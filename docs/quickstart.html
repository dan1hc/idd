IDD Quick Start

Make AI coding tools follow your project's conventions.

1. Install

curl -fsSL https://raw.githubusercontent.com/dan1hc/idd/main/install.sh | bash

This scaffolds the IDD file tree and copies instructions.md to where AI tools look (.cursorrules, CLAUDE.md, .github/copilot-instructions.md).

2. Populate conventions

Open Cursor, Claude Code, or GitHub Copilot and prompt:

Populate conventions.json for this project.

The AI reads your actual code — manifest files, configs, source files — and writes conventions.json. No bash heuristics. You do this once. Every session after, the AI reads the populated conventions automatically.

3. Build features

Prompt with what you want to build:

Add a POST /users endpoint with input validation.

The AI reads your conventions + learned rules, creates a feature spec, writes code that matches your project's patterns, and updates the feature glossary so the next session knows what exists.

Teaching project rules

When conventions alone aren't enough, teach explicit rules:

.github/idd/idd learn "Always use BaseClient, never raw httpx"

Rules persist in learned.json and take precedence over detected conventions.

File tree

.github/idd/
├── idd                     # CLI (init, learn)
├── instructions.md         # copied to AI tool locations
├── conventions.json        # project conventions (AI-populated)
├── learned.json            # human-confirmed rules
├── features/
│   ├── _template.md        # feature spec template
│   └── *.md                # your feature specs
└── schemas/
    └── conventions.schema.json
